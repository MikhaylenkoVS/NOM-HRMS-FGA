# Code Review: Reliability First — ревью с приоритетом надёжности

Основной скилл рецензирования кода для проекта. Расширяет и переопределяет
общие правила `code-review-assistant` с учётом специфики NOM-HRMS-FGA:
научный код, масс-спектрометрия, tkinter GUI, десктоп-сборка.

## Порядок приоритетов (нерушимый)

| # | Приоритет | Что проверять |
|---|-----------|--------------|
| 1 | **Стабильность** | Не падает ли программа? Все ли ветки обработаны? None/NaN? |
| 2 | **Корректность** | Правильный ли химический/алгоритмический результат? |
| 3 | **Тестируемость** | Можно ли написать тест? Есть ли крайние случаи? |
| 4 | **Читаемость** | Понятен ли код другому химику-разработчику? |
| 5 | **Производительность** | Тормозит ли на реальных данных (>1000 пиков)? |
| 6 | **Стиль** | flake8 (max-line-length=120), именование, docstring |

**Правило эскалации:** если изменение улучшает стиль, но ухудшает
стабильность — ОТКЛОНИТЬ. Если изменение улучшает производительность ценой
читаемости — ОТКЛОНИТЬ (кроме случаев явно измеренного бутылочного горлышка).

## Карта критических зон по модулям

### `src/core/spectrum_ops.py` (49K — наивысший приоритет)

**Критичные функции** (изменения → обязательный ручной прогон тестов):
- `assign_formulas()` — ядро метода. Любая правка логики scoring.
- `find_series()` — поиск гомологических серий. Правка max_consecutive_misses, allow_gaps.
- `_generate_candidate_formulas()` — генератор формул. Правка диапазонов.
- `load_spectrum()` — загрузка CSV. Правка CSV_COLUMN_MAPPER.

**Что ловить:**
- Хардкод вместо `CHEM`/`PIPELINE` (приоритет №1 — см. `config-safety-audit`).
- Отсутствие проверки `pd.isna()` перед арифметикой.
- `df.copy()` забыт → модификация исходного DataFrame.
- Сигнатура с `**kwargs` для обратной совместимости — не удалять без плана миграции.

### `src/core/pipeline.py` (61K — высокий приоритет)

**Что ловить:**
- Изменение порядка шагов пайплайна без обновления `PipelineStats`.
- `test_mode=True` влияет на production-путь.
- Пути не проверяются на `None` и `Path.exists()`.

### `src/configs/` (высокий приоритет)

**Что ловить:**
- Изменение точных значений в `chemistry.json` (массы, Δ).
- Добавление ключа в JSON без обновления loader или без использования.
- Дублирование значения в `loader.py` вместо ссылки на JSON.

### `src/app.py` (82K — средний приоритет)

**Что ловить:**
- Блокировка GUI главным потоком (pipeline без threading).
- Tkinter-операции из фонового потока (должен быть `queue.Queue`).
- Жёсткая зависимость от `src.ui`/`src.structures` (должен быть fallback).

### `src/testing/`, `src/simulations/` (средний приоритет)

**Что ловить:**
- Smoke-тест меняет production-данные.
- Генератор тест-сетов использует случайные seed без возможности воспроизведения.

### `tests/` (средний приоритет)

**Что ловить:**
- Новый тест без маркера.
- Хардкод ppm/порогов вместо `PIPELINE`.
- Тест только на set_01 для integration (должны быть все 5).

## Шаблон ответа при ревью

### Общий вывод
Одна фраза: «Изменение корректно, замечаний нет» / «Есть N проблем, требуется
доработка» / «Нужны уточнения перед ревью».

### Проблемы (по приоритетам)

```
### 🔴 Стабильность
- [file:line] Описание. Сценарий падения. Критичность.

### 🟠 Корректность
- [file:line] Описание. Какие кейсы ломаются.

### 🟡 Тестируемость
- [file:line] Какие тесты нужны.

### 🟢 Читаемость
- [file:line] Что запутывает.

### ⚪ Производительность
- [file:line] Проблема только если измерима.

### 🔵 Стиль
- [file:line] Мелкие замечания.
```

### Предложенные изменения

- Обязательные (блокируют merge).
- Рекомендательные (можно в следующем PR).

## Специфичные для проекта антипаттерны

### Химический код
1. **Хардкод ppm/масс** — всегда ошибка (приоритет 🔴).
2. **Сравнение `== True` с булевой колонкой DataFrame** — `E712` во flake8,
   но в контексте `assign == True` может дать неожиданный результат, если
   колонка содержит не bool.
3. **DBE без max(0, ...)** — отрицательные DBE бессмысленны, но не фатальны.
4. **H/C без проверки C > 0** — ZeroDivisionError (приоритет 🔴).

### GUI-код
5. **`root.update()` в цикле** — замораживает GUI.
6. **matplotlib Figure без `plt.close(fig)`** — утечка памяти.
7. **Импорт RDKit без try/except** — ломает fallback.

### Python-общие
8. **default mutable argument** (`def f(x=[])`) — классика.
9. **Голый `except:`** — глотает KeyboardInterrupt.
10. **`import *`** — замусоривает namespace, неясно что откуда.

- [ ] Интеграционные тесты проходят (`pytest tests/integration/`).

- [ ] Маркеры pytest проставлены.
- [ ] Изменения в `chemistry.json` проверены на точность значащих цифр.
- [ ] После изменений в GUI — проверен запуск `python -m src`.
- [ ] `git diff` не показывает случайных изменений в соседних файлах.
