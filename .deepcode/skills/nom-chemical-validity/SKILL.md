# NOM Chemical Validity — химическая валидность формул

Проверка брутто-формул на принадлежность к природному органическому веществу
(NOM). Два уровня фильтрации: жёсткие бинарные критерии (прошёл / отброшен) и
мягкие скоринговые (влияют на ранг кандидата). Частая проблема: просачивание
высокоазотистых формул — требует усиления N/C-фильтра или soft-штрафа.

## Жёсткие критерии (бинарные — отбрасывают кандидата)

Эти критерии применяются в `_generate_candidate_formulas()` **до** конверсии
в ионную массу. Если кандидат не проходит хотя бы один — он исключается
безвозвратно.

### 1. DBE (Double Bond Equivalent)

```python
DBE = max(0, 1 + C − H/2 + N/2)
```

- **Порог:** DBE ≤ 30.0 (`max_dbe`)
- **Химический смысл:** сумма колец и двойных связей. DBE > 30 означает
  чрезвычайно конденсированную ароматическую систему, нехарактерную для NOM.
- **Отрицательные DBE** (H слишком много для данных C и N) зажимаются в 0
  функцией `max(0, ...)` — это нормально, валентно-невозможные формулы
  отсеиваются генератором на другом этапе.
- **Что может пойти не так:** при больших N (>10) DBE может быть искусственно
  завышен (правило рассчитано на нейтральные молекулы, не на заряженные формы
  с N⁺). Это known limitation.

### 2. H/C — отношение водород/углерод

- **Порог:** H/C ≤ 3.0 (`max_hc`)
- **Химический смысл:** алканы (H/C ≈ 2), алкены (≈1.5–2), ароматика (0.5–1.5).
  H/C > 3 практически не встречается у органических молекул с C≥2 (только CH₄
  имеет H/C=4).
- **Краевые случаи:** метанол CH₃OH — H/C=4. Но он не попадает в NOM-диапазон
  масс.

### 3. O/C — отношение кислород/углерод

- **Порог:** O/C ≤ 1.2 (`max_oc`)
- **Химический смысл:** углеводы (O/C ≈ 1), карбоновые кислоты (≈0.5–0.8),
  лигнин (≈0.3–0.5). O/C > 1.2 — пероксиды или полиолы, не NOM.
- **Краевые случаи:** щавелевая кислота C₂H₂O₄ — O/C=2. Отсеивается. Это
  осознанно — C₂ находится за пределами NOM-диапазона масс (>100 Da).

### 4. N/C — отношение азот/углерод

- **Порог:** N/C ≤ 1.0 (`max_nc`)
- **Химический смысл:** аминокислоты (≈0.2–0.3), пептиды (≈0.2–0.3),
  гетероциклы (≈0.1–0.5). Белковые молекулы не превышают N/C≈0.5.
  N/C > 1.0 — практически только взрывчатка (TNT, RDX) или азотистые
  основания.
- **Известная проблема:** высокоазотистые формулы просачиваются. Текущий
  порог N/C=1.0 может быть слишком либеральным. Рекомендуется ужесточить
  до 0.5–0.7 и/или добавить soft-штраф на N в скоринге.

### 5. min_c — минимальное число углерода

- **Порог:** C ≥ 1 (`min_c`)
- **Химический смысл:** органическая молекула должна содержать углерод.

## Мягкие критерии (scoring — влияют на ранг)

Применяются в `assign_formulas()` после фильтрации кандидатов в ppm-окно.
Кандидат с минимальным score выбирается как лучший.

### 1. NOM-расстояние (`_nom_distance`)

```
score = nom_weight * nom_distance + penalties
```

- `_nom_distance(hc, oc)` = минимальное евклидово расстояние от (O/C, H/C)
  до центров NOM-областей Ван-Кревелена.
- Центры вычисляются как среднее вершин полигонов из `NOM_REGIONS`
  (src/core/van_krevelen.py).
- Если H/C ≤ 0 → +10.0 (заведомо не-NOM).
- `nom_weight` = 1.0 по умолчанию в `assign_formulas()`.

**Области NOM_REGIONS** (определены в van_krevelen.py):
- Lipid (липиды): низкий O/C, высокий H/C
- Protein (белки): средний O/C, средний H/C
- Amine sugar (аминосахара): средний O/C, средний H/C
- Lignin (лигнин): средний O/C, низкий H/C
- Carbohydrate (углеводы): высокий O/C, средний H/C
- Tannin (таннины): высокий O/C, низкий H/C
- Condensed aromatic (конденсированная ароматика): низкий O/C, очень низкий H/C

### 2. Изотопный фильтр Бейнона

Включается флагом `isotope_filter=True` в `assign_formulas()`. Требует
`original` — ссылку на исходный (pre-denoise) спектр.

**Алгоритм:**
1. `_beynon_m1_ratio(counts)` — теоретическое (M+1)/M:
   - ¹³C: 1.1% на атом C
   - ²H: 0.015% на атом H
   - ¹⁷O: 0.04% на атом O
   - ¹⁵N: 0.37% на атом N
   - Результат в долях (не %), например 0.078 для C₇H₆O₂.

2. `_measure_m1_ratio(mass, original_spec, ppm_tol=5.0)` — реальное (M+1)/M:
   - Ищет пик на `mass + 1.00335` Da (разница масс ¹³C−¹²C).
   - В пределах ppm_tol (5.0 ppm).
   - Возвращает `I(M+1) / I(M)` или None.

3. Если |реальное − теоретическое| / теоретическое > 20% (`_ISOTOPE_TOLERANCE`):
   - Штраф +2.0 к score (`_ISOTOPE_PENALTY`).

**Ограничения:**
- Работает только для CHON. S, P, Cl, Br имеют другие изотопные паттерны.
- M+1 пик должен быть виден в исходном спектре (до денойзинга).
- При низкой интенсивности M+1 шум может исказить отношение.

### 3. Штрафы (penalties)

В текущей реализации penalties — это только изотопный штраф. Но архитектура
позволяет добавить:
- **N-штраф:** penalty = k × (N/C − 0.5) при N/C > 0.5 — борется с
  высокоазотистыми «паразитами».
- **O-штраф:** penalty для O/C > 1.0 в низкомассовой области.
- **DBE-штраф:** растёт с DBE для массового диапазона — DBE не должен превышать
  C/2 (практически недостижимо для алифатических).

## Как вычисляются отношения (проверка реализации)

Все отношения должны вычисляться ТОЛЬКО через проверку C > 0 (деление на ноль):

```python
hc = H / C if C > 0 else float('inf')
oc = O / C if C > 0 else float('inf')
nc = N / C if C > 0 else float('inf')
```

**Антипаттерн:** `hc = H / C` без проверки C > 0 → ZeroDivisionError или inf.

## Известные проблемы и направления улучшения

1. **Высокоазотистые формулы** — главный источник ложных назначений.
   Предлагаемые решения:
   - Ужесточить `max_nc` с 1.0 до 0.5 (или 0.7 с мягким штрафом).
   - Добавить N-штраф в penalties: `+2.0 * max(0, N/C - 0.5)`.
   - Учитывать N-rule (азотное правило): для [M–H]⁻ нечётная номинальная
     масса → чётное число N (или наоборот — зависит от соглашения).

2. **DBE для заряженных форм.** Текущая формула DBE не учитывает формальный
   заряд на азоте (N⁺ меняет DBE). Для [M–H]⁻ с депротонированной COOH это
   не критично, но если появятся другие ионные формы — потребуется коррекция.

3. **Изотопный фильтр:** не различает M+1 от ¹³C и M+1 от дейтерия.
   При дейтерометилировании/дейтероацилировании в derivatized-спектрах
   M+1 паттерн искажается — фильтр должен применяться только к original.
