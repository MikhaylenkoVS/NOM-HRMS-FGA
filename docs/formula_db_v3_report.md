### Найденная и исправленная ошибка: семантика водорода

В базе v3 хранится **водород каркаса** ``h`` (до замещения галогенами): для кода
``(C,N,O,S,P,X)`` масса равна ``base + h·m(H) + Δ``, где ``Δ = Σ n_x·(m_X − m(H))``,
то есть фактическая формула — ``C…H_(h−x)X_x``. Первая версия читателя отдавала
``h`` вместо ``h − x``: массы были верны, а количества водорода — завышены на число
галогенов. Найдено при сравнении со слоем подстановок (расхождение наборов при
совпадении масс). Исправлено в `_reader_v3.py` (``H = h − x``), тесты и отчёт
обновлены. Эффект: путь «база» перестал терять/искажать галогенные формулы —
например, на `set_01` база теперь назначает 157 пиков, как и перебор.

**Скорость на этапе назначения** (`db_candidates`, 200 случайных масс 150–800 Да, 5 ppm):

| v2 CHNOSP + слой подстановок | 88.4 | 222.7 |
| **v3 CHNOSPHal (галогены в базе)** | **28.0** | **354.0** |

Ускорение на назначении — ×3.16.

## 6c. Почему слой подстановок и база CHNOSPHal дают разное

Инструмент `tools/diagnostics/compare_halogen_paths.py` сравнивает наборы кандидатов
на одних и тех же пиках: слой (v2 CHNOSP + подстановки), CHNOSP без подстановок и
базу v3. Результат по 5 тест-сетам (по 100 пиков):

| Метрика | Значение |
|---|---|
| Формулы только в слое (нет в базе) | **0** |
| Расхождения масс при одинаковых формулах | **0** |
| Формулы только в базе (слой не догенерировал) | 2 278–3 611 на сет (≈4.7 % кандидатов базы) |
| Совпавшие наборы кандидатов | 47–61 % пиков |

**Причина единственная и измерена: ``parent_outside_window``.** Слой строит
замещённую формулу из родительской CHNOSP-формулы: он ищет родителя в базе v2 по
центру ``масса пика − Δ``. Допуск ppm применяется **дважды** — сначала при поиске
родителя, затем при проверке конечной формулы против пика. Если пик смещён к краю
окна, родитель оказывается за его пределами: измеренное смещение **5.1–19.4 ppm
(в среднем 7.4) при допуске 5 ppm**. База v3 хранит замещённые формулы
непосредственно, поэтому делает один поиск по одному допуску и кандидатов не теряет.

То есть расхождение — не ошибка данных, а следствие двухступенчатой схемы слоя:
база v3 является строгим надмножеством слоя по составу и точна по массам.
