# Референс: длина CD3/CD3CO серий без фильтров (F16)

Дата: 2026-10-21. Данные: restricted assign (C5–60, H4–120, O1–30, N≤5,
S≤2, P≤1, Cl≤2, F/Br/I=0, NOM-ratio), GMM 2.0.
Скрипт: `tools/diagnostics/reference_length_no_filters.py`.
Артефакт: `D:/Temp/User/reference_length_no_filters.json`.

Это **не** рабочая политика и не валидация. Это верхняя точка отсчёта:
сколько шагов вообще можно найти, если вообще не фильтровать.

## 1. Правило

* Якорь — исходный пик с формулой, O ≥ 1.
* Для степени n ожидаемая m/z: μ = m0 + n·Δ.
* Шаг считается подтверждённым, если в окне μ ± h есть **хотя бы один**
  пик дериватизата.
* Ни profile, ни вычитание исходника, ни FDR, ни reliability не
  применяются.
* Серия обрывается на первом пропуске; максимум степени — 10.
* Окна: абсолютные 0.0003 и 0.0005 Да; ppm 0.5, 1.0, 3.0, 5.0.

Два средних:

* `mean_all` — среднее по всем якорям, включая якоря с нулём;
* `mean_pos` — среднее только по якорям, где найден хотя бы один шаг.

## 3. Что это значит

1. **Верхняя оценка длины.** Если вообще не фильтровать, серии с хотя бы
   одним шагом имеют в среднем 1.6–1.9 шага при 0.0003–0.0005 Да и 2.9–3.2
   при 3–5 ppm. Это верхняя граница того, что вообще есть в спектре.
2. **Максимум 7–8 при узких окнах, 10 — при широких.** При 0.0003 Да
   максимальная найденная длина 8 (CD3) и 7 (CD3CO); при 0.0005 — 10 и 8;
   при 3–5 ppm — 10. Искать степени выше 8–10 при таких окнах бессмысленно:
   дальше уже нет пиков, а не «фильтр мешает».
3. **Широкое окно добавляет не только длину, но и шум.** При 5 ppm доля
   якорей с ≥2 шагами 57–59 %, но это уже включает случайные совпадения;
   без фильтров это не доказательство серии.
4. **Для сравнения с reliability v2:** при 0.0003 средняя подтверждённая
   длина 0.442/0.454, а без фильтров `mean_pos` 1.87/1.65. То есть
   reliability-фильтр срезает примерно 75 % даже тех шагов, которые
   формально «есть по массе». Это ожидаемо: без фильтров любой пик в окне
   считается шагом.

## 4. Ограничения

* Якоря — restricted assign, O ≥ 1; другие формулы не рассматриваются.
* Шаг не проверяется по profile/исходнику: это именно «no filters».
* Окно 0.0003/0.0005 Да при m/z 400–500 уже FWHM, поэтому часть шагов —
  наложения; для референса это нормально.
