## T0.1. Link-level валидация на синтетике

**Вопрос:** правильно ли пик включён в связь «исходный компонент — степень —
продукт», а не только «серия найдена».

**Данные:** `data/test_sets/set_01…set_05`:
`annotations.csv` (`compound_id`, `derivatization_state`, `is_signal`,
`peak_id`, `mass_obs`), `molecules.csv` (`carboxyl_count`, `hydroxyl_count`).

**Метрики:**
- precision/recall связей;
- доля завышенной максимальной степени;
- доля пропущенных известных степеней;
- заявленная vs фактическая частота ошибок.

**Протокол:** настройка на `set_01–03`, оценка на `set_04–05`.

**Артефакт:** `tools/diagnostics/link_validation.py`, отчёт в
`docs/statistical_processing_design.md` (§14).

**Приёмка:** метрики посчитаны для текущего пайплайна и для каждого нового
критерия; сравнение при равном FPR.

## T0.2. Валидность decoy

**Вопрос:** воспроизводит ли decoy именно наши ложные назначения, особенно
ложные продолжения настоящих серий.

**Что сделать:**
- prefix-preserving контроль: реальный префикс + случайное продолжение;
- сравнить распределение p для шагового, шаблонного и prefix-preserving null;
- bootstrap-CI и верхнюю границу FDR; не отчитываться `q=0` как «ошибок нет»;
- проверить, что контроль повторяет весь выбор длины/кандидата.

**Приёмка:** на контроле доля отвержений при выбранном α не выше номинала;
для ложных продолжений оценка не занижена.

---

## T0.3. Откалиброванный массовый score

**Вопрос:** насколько близость к ожидаемой массе необычна для данного участка
спектра.

**Признаки:** ppm-остаток, локальная плотность, число альтернатив в окне,
пропуск, конкурентность.

**Метод:** эмпирические распределения f_0 (контроль) и f_1 (target);
простая модель 3–5 признаков; проверка на synthetic и decoy.

**Приёмка:** калибровка на отложенных данных; score лучше голого ppm-окна
при равном FPR.

## T1. Cross-support CD3/CD3CO

**Вопрос:** подтверждается ли назначение независимой реакцией.

**Метод:** join по `(mass_src, brutto)`; шкала 0/1/2; отсутствие серии во
второй реакции — не минус; нулевое пересечение — по decoy/перестановке.

**Приёмка:** прирост link precision при равном FPR на синтетике; на F16 —
обогащение `formula_ok`/`persistence` при сопоставимой длине.

---

## T2. Continuation test

**Вопрос:** принадлежит ли последняя ступень серии или она случайна.

**Метод:** условный тест по префиксу; контроли A (сдвиг шаблона), B (сдвиг
шага), C (prefix-preserving); `supported_max_degree`; калибровка α по decoy;
BH-q при отчётности.

**Приёмка:** снижает завышение максимальной степени, не снижая recall связей;
на контроле доля ложных продолжений ≤ номинала.

---

## T3. Глобальное разрешение конфликтов

**Вопрос:** какое сочетание серий лучше объясняет пики.

**Метод:** веса + мягкий штраф за общий пик; точный перебор по кластерам
(2–10 серий, максимум 10); alias/partial/same-precursor; сравнение с
независимым назначением.

**Приёмка:** link precision выше, чем при независимом назначении; реальные
общие сигналы не уничтожаются; устойчивость к λ.

---

## T4. Likelihood/PEP

**Вопрос:** какова вероятность ошибки отдельной серии.

**Метод:** признаки T0.3 + T1 + T2; смесь f_0/f_1, EM; калибровка
leave-one-decoy-out; q не использовать как признак.

**Приёмка:** калибровочная кривая и AUC на отложенных decoy; топ-PEP
обогащён `formula_ok`/`cross_support`.

## T12. Reliability v2: reliable/ambiguous, без FDR (completed)

**Правило:** `reliable` = n_deriv≥1 и n_src=0, либо при
n_src=M≥1 profile разрешает ≥1+M пиков; `ambiguous` = пик
есть, но profile не разрешил; `absent` = n_deriv=0.
`unconfirmed/unreliable` не различаются. FDR и `prefix` не используются.

**Длина:** идём по n, пока n_deriv≥1; подтверждённая длина —
последний `reliable`, `ambiguous` на промежуточных шагах допустимы;
неподтверждённая — последний `ambiguous`, если он больше.

**Числа:** при h=0.0003 `PPD_deriv` 0.213/0.242, `PPD_src` 0.109/0.131,
сумма 0.322/0.374; `reliable` 17.3/18.0 %, `ambiguous` 4.0/6.3 %,
`absent` 78.7/75.8 %; средняя подтверждённая длина 0.442/0.454, 77/73 %
якорей без надёжного шага. Profile-подтверждение 1+M добавляет всего
+10/+11 позиций при 0.0003 и +1 177/+625 при 0.0010 (FWHM 0.0004–0.0009).

**Артефакт:** `docs/reliability_policy_f16.md`,
`tools/diagnostics/reliability_policy_f16.py`.

## T13. Референс длины без фильтров (completed)

**Правило:** шаг подтверждён, если в окне μ ± h есть хотя бы один пик
дериватизата; без profile, вычитания, FDR и reliability; обрыв на первом
пропуске; max степень 10.

**Числа:** при 0.0003 Да `mean_pos` 1.87/1.65, `mean_all` 0.48/0.50,
доля нулей 74/70 %, max 8/7. При 0.0005 Да 2.17/1.93, нулей 63/58 %,
max 10/8. При 5 ppm 3.22/2.90, нулей 20 %, max 10.

**Вывод:** это верхняя граница; искать степени выше 8–10 при узких окнах
бессмысленно. Reliability v2 срезает ~75 % шагов относительно этой границы.

**Артефакт:** `docs/reference_length_no_filters_f16.md`,
`tools/diagnostics/reference_length_no_filters.py`.
