# NOM-HRMS FGA v0.10.1

Патч-релиз с исправлениями интерфейса.

## Интерфейс

- Исправлены наложения элементов на вкладке «Файлы»: предупреждение об
  экспериментальном RT-режиме больше не перекрывает блок входных спектров.
- Вкладка «Фильтры» переразложена по секциям: изотопы, галогены,
  шумоподавление, ограничения NOM, база формул.
- Длинные пояснения убраны из GUI; они перенесены в документацию.
- Добавлена кнопка «📖 Руководство пользователя».
- Все внутренние вкладки параметров получили вертикальную прокрутку.
- Переработаны окна «Список изотопов», «Настройки поиска по галогенам» и
  «База формул»: таблицы/прокрутка, компактные размеры, центрирование.
- Убран дублирующий переключатель шумоподавления дериватизатов.

## Сборка

- Exe собран с UPX, тесты и test-данные исключены.
- В exe входит CHNOSP-база; CHNOSPHal скачивается отдельно из окна
  «База формул».
