# NOM-HRMS FGA v0.10.0

## Основное

- Политика серий v3: надёжная/неоднозначная длина, confidence, O-лимит,
  штрафы за source overlap, изотопы, gaps, конфликты.
- Profile-разрешение наложений по RAW, все доступные сканы.
- Попарное изотопное разрешение: правило 3× теоретической интенсивности.
- Веса штрафов вынесены в `PenaltyWeights`; добавлены evidence-поля для
  калибровки.
- FDR-калибровка F16: при q=0.05 минимальная длина CD3 = 6, CD3CO = 7.
  Показано, что веса source/O/conflict не меняют FDR на сэмпле — нужен
  per-step анализ в будущем.

## Сборка

- Exe собирается с UPX, тесты и test-данные исключены.
- В exe входит обязательная CHNOSP-база (36 МБ); CHNOSPHal (538 МБ) —
  отдельно.
- Добавлена кнопка «Скачать CHNOSPHal» в окне «База формул»: загрузка с
  GitHub Releases, SHA-256, докачка, установка в пользовательский каталог.
- Автообновление exe по GitHub Releases.
