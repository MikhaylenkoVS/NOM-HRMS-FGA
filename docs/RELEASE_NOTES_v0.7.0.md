# NOM-HRMS-FGA v0.7.0 — Инструменты пользователя

**2026-08-19** | [Full changelog](https://github.com/MikhaylenkoVS/NOM-HRMS-FGA/compare/v0.6.1...v0.7.0)

Первый минорный релиз направления «Инструменты пользователя»: пакетная обработка,
гистограммы распределений, экспорт результатов в JSON/Excel, компактный PDF-отчёт
и оптимизация формулы-присваивания.

---

## ✨ Новые возможности

| # | Описание |
|---|----------|
| — | **Batch-обработка** — папка с несколькими наборами → сводная таблица сравнения (sample, Σ N_COOH, Σ N_OH, avg mass), экспорт CSV/XLSX/JSON. |
| — | **Гистограммы распределений** — O/C, H/C, DBE, AI (ароматический индекс), N_COOH, N_OH; отдельная вкладка, экспорт PNG/SVG. |
| — | **Экспорт результатов в JSON/Excel** — `.json` (с метаданными: версия/параметры/дата), `.xlsx` (автоширина колонок); загрузка CSV/XLSX/JSON. |
| — | **PDF-отчёт** — компактный документ: параметры анализа, сводная статистика, таблица результатов, диаграмма Ван-Кревелена, гистограммы. |
