# Release Notes v0.9.0

**Дата:** 2026-10-13
**Тип:** научное изменение + производительность

## Кратко

Назначение формул переведено на **сжатую базу формул** (быстро) с галогенным
слоем поверх неё, изотопные проверки стали частью обычного прогона: паттерн
M+1/M+2 влияет на выбор формулы, для найденных формул ищутся изотопные
варианты, а пики-сателлиты помечаются и не попадают в отчёт как отдельные
соединения. Появилось окно со списком изотопов.

## Производительность

| Прогон | Было (v0.8.0) | Стало (v0.9.0) |
|---|---|---|
| set_01, полный CLI (316 пиков) | ~66 с | **~11 с** |
| Назначение на пик | 50–450 мс (перебор) | 5–185 мс (база), ~12 мс типично |

* Кандидаты берутся из `data/formula_db/*.fdb` (79 576 593 формулы CHNOSP,
  0.1 Да-бины, zstd) через `FormulaDatabaseReader`.
* Галогены (F, Cl, Br, I) добавляются слоем подстановок: дополнительный запрос
  по массе `m − Δ(галогены)`. Слой включается **по изотопному свидетельству**
  (M+2 ≥ 5 % — характерно для Cl/Br) или когда CHNOSP-кандидатов в окне нет.
* Если файл базы недоступен — назначение автоматически работает перебором
  (медленнее, результат эквивалентен).

## Изотопы в обычном прогоне

* **Изотопный фильтр включён по умолчанию** (`isotope_filter=True`):
  расхождение теоретического M+1/M+2 с наблюдаемым даёт штраф, совпадение M+2
  для S/Cl/Br — бонус.
* **Поиск изотопных вариантов** (`isotope_variants=True`): для каждой найденной
  формулы ищутся её варианты (`13C`, `2H`, `15N`, `17O`, `18O`, `33S`, `34S`,
  `37Cl`, `81Br`, …) и сравниваются отношения измеренной и теоретической
  интенсивностей. Результат — в колонке `iso_variants` отчёта
  (например, `13C 0.077/0.076`).
* **Атрибуция сателлитов**: пик, который тяжелее другого пика на Δ и чьё
  отношение интенсивностей совпадает с теоретическим, помечается
  (`iso_satellite_of`, `iso_satellite_label`) и **исключается из отчёта** —
  он не является самостоятельным соединением.
* CLI: `--isotope-variants`; GUI: галочка «Искать изотопные варианты».
* Отключить: `--isotope-filter` не задавать нельзя (включено по умолчанию) —
  используйте Python API `run_pipeline(isotope_filter=False, isotope_variants=False)`.

## Интерфейс

* Кнопка **«📋 Список изотопов…»** на вкладке «Параметры → Фильтры» открывает
  отдельное окно с таблицей: элемент, изотоп, масса (Да), природная
  распространённость (%). Таблица не загромождает основные вкладки.
* Обновлены подписи фильтров (M+1/M+2 по таблице изотопов вместо формулы
  Бейнона).

## Исправлено

* **Сжатая база формул была нерабочей**: `formula_to_string()` включала в строку
  служебный ключ `mass_u` (`C9H10N4O2P2Smass_u29999997075040`), а
  `SearchResult.counts` содержал этот ключ. Исправлено в
  `src/core/formula_db/_packed.py` и `_reader.py`.
* Пределы выдачи базы увеличены (20 000 → 200 000), иначе часть кандидатов в
  плотных массовых окнах терялась.
* ppm-допуск поиска изотопных вариантов и сателлитов вынесен в конфиг
  (`variant_ppm_tol`, по умолчанию 5 ppm) — иначе на реальных спектрах
  варианты почти не находились.
* Изотопные сателлиты больше не попадают в отчёт как самостоятельные формулы.

## Совместимость

* Формат отчёта расширен колонками `iso_variants`, `iso_satellite_of`,
  `iso_satellite_label` (порядок прежних колонок сохранён).
* Новых обязательных зависимостей нет: `zstandard` уже был в
  `requirements.txt`; в spec добавлены data-файлы базы и hidden-импорты.
* Размер `.exe` растёт на ~39 МБ (внутрь кладётся база формул).
