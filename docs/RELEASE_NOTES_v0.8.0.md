# Release Notes v0.8.0

**Дата:** 2026-10-13
**Тип:** научное изменение (feature + bug fix)

## Кратко

Назначение брутто-формул расширено с CHNO на **C, H, O, N, S, P, F, Cl, Br, I**,
а изотопный контроль переведён с одной эмпирической формулы (Бейнон, M+1) на
**таблицу изотопов** с расчётом паттерна M/M+1/M+2 и поиском изотопных вариантов
найденной формулы.

## Новое

### Элементы
* Набор элементов и диапазоны — в `src/configs/constants/formula_search.json`:
  C 1–50, H 4–100, O 0–25, N 0–10, S 0–5, P 0–5, F 0–5, Cl 0–5, Br 0–3, I 0–3.
* Моноизотопные массы F, Cl, Br, I добавлены в `src/configs/chemistry.json`.
* Новые ограничения: отношения S/C, P/C и X/C (X — сумма галогенов),
  DBE считается как `(2C + 2 + N + P − H − X)/2`, соблюдается правило чётности
  валентностей.
* GUI: поля диапазонов строятся из конфига — новые элементы появляются
  автоматически.
* CLI: `--element-ranges "C:5-60,H:4-120,O:1-30,N:0-3,S:0-2,Cl:0-1"`.

### Изотопы
* Новая таблица изотопов (масса + природная распространённость) в
  `src/configs/constants/isotope.json`.
* Новый модуль `src/core/spectrum/_isotopes.py`:
  * `pattern()` — теоретический паттерн M/M+1/M+2 (свёртка; корректно для
    Cl/Br/S, где определяющим является M+2);
  * `variants()` — изотопные варианты формулы (`13C`, `2H`, `15N`, `17O`, `18O`,
    `33S`, `34S`, `37Cl`, `81Br`, …) с точным сдвигом массы и вероятностью;
  * `find_isotope_variants()` — сопоставление вариантов с наблюдаемыми пиками;
  * `measure_pattern()` — измерение M+1/M+2 в спектре.
* При включённом **Изотопном фильтре** изотопный паттерн влияет на выбор
  формулы: расхождение M+1/M+2 даёт штраф, совпадение M+2 для S/Cl/Br-формул —
  бонус.
* Формулы с S/P/галогенами без изотопного подтверждения не перебивают
  CHNO-вариант в том же ppm-окне (защита от ложных назначений).
* Новая колонка `iso_variants` при `isotope_variants=True` (Python API).

## Исправлено

* **DBE в скоринге:** использовался кислород вместо азота
  (`1 + C − H/2 + O/2` → `(2C + 2 + N + P − H − X)/2`). Влияло на штраф за
  экзотически высокий DBE.
* `_counts_to_str` больше не ограничен CHNO — строки формул собираются для
  любого набора элементов (для CHNO-формул формат не изменился).
* PyInstaller: `distutils` удалён из исключений spec-файла (на Python ≥ 3.12
  сборка падала с `ValueError: Target module "distutils" already imported`).

## Производительность

* Назначение выполняется **под каждый пик** в узком окне ±ppm (кэш окон по
  сетке 0.001 Да), а не перебором всех формул до 1000 Да.
* Цена: назначение на set_01 (316 пиков) — ≈66 с (ранее ≈2 с). Для спектров с
  десятками тысяч пиков требуется переход на сжатую базу формул
  (`data/formula_db`) — запланировано отдельной задачей (ADR-0004).
* Замеры пределов: при X/C = 0.1 на m/z 800 в окне ±5 ppm — ~2 400 кандидатов
  (0.45 с), при X/C = 0.5 — ~21 000 (3.9 с). Поэтому дефолты умеренные.

## Совместимость

* Формат выходной таблицы не изменился.
* Для CHNO-формул строки (`C7H6O2`) и поведение скоринга сохранены.
* Новых runtime-зависимостей нет.
