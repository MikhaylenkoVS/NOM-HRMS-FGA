## Правила

- После **каждого шага**: `pytest` должен быть зелёным
- После **каждого модуля**: `python -m src` должен запускать GUI
- Имена модулей: публичные классы/функции — без префикса, приватные — с `_`
- `__all__` в `__init__.py` каждого пакета содержит полный список экспорта
