# План рефакторинга крупных модулей

> **Создан:** 2026-08-04 | **Статус:** 🔴 план | **Цель:** v0.7

## Проблема

Два модуля выросли до неподдерживаемых размеров:

| Файл | Размер | Проблемы |
|------|:---:|----------|
| `src/core/pipeline.py` | 61K, ~1600 строк | Монолит: run_pipeline + test_eval + все хелперы в одном файле |
| `src/app.py` | 82K, ~1700 строк | Монолит: все вкладки GUI + логика + импорты в одном файле |

Сложность автоматических правок (прогресс-бар, кэш) показала: файлы слишком велики для безопасного рефакторинга.
