# План рефакторинга крупных модулей

> **Создан:** 2026-08-05 | **Статус:** 🔴 план | **Цель:** v0.7

## Проблема

Четыре модуля выросли до неподдерживаемых размеров. Автоматические правки ломают отступы,
ручная навигация затруднена.

| # | Файл | Строк | Проблема |
|---|------|:---:|----------|
| 1 | `src/app.py` | 1862 | 50 методов в одном классе `App`. Все вкладки + логика + импорты в одном файле |
| 2 | `src/core/pipeline.py` | 1679 | `run_pipeline` + test eval + 4 датакласса + хелперы + кэш в одном файле |
| 3 | `src/core/spectrum_ops.py` | 1232 | ~20 функций: загрузка, денойз, генератор, assign, find_series, build_table, визуализация |
| 4 | `src/core/fragments.py` | 1161 | ~80 фабричных функций + класс `MoleculeFragment` + библиотека фрагментов |

---

## Порядок выполнения

```
Этап 1 (spectrum_ops) → Этап 3 (fragments) → Этап 2 (pipeline) → Этап 4 (app)
```

Этапы 1-3 — чистый рефакторинг, логика не меняется, тесты должны проходить после каждого.
Этап 4 — требует аккуратности из-за tkinter-связей через `self`.

## Критерий приёмки

- [ ] `pytest tests/` — 318+ тестов зелёные после каждого этапа
- [ ] `python -m src` — GUI запускается
- [ ] Ни одного файла >500 строк в `src/core/` и `src/ui/`
