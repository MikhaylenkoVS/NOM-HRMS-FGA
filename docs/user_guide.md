## 1. Установка

### Windows — .exe (рекомендуется)

1. Скачайте `NOM_HRMS_FGA.exe` со страницы [Releases](https://github.com/MikhaylenkoVS/NOM-HRMS-FGA/releases)
2. Запустите двойным кликом — установка не требуется
3. При первом запуске Windows SmartScreen может показать предупреждение:
   нажмите **«Подробнее»** → **«Выполнить в любом случае»**

### Windows / macOS / Linux — pip

```bash
pip install git+https://github.com/MikhaylenkoVS/NOM-HRMS-FGA.git
nom-hrms-fga
```

Требуется Python ≥ 3.10. На Linux дополнительно: `sudo apt install python3-tk`.

### Для разработчиков

```bash
git clone https://github.com/MikhaylenkoVS/NOM-HRMS-FGA.git
cd NOM-HRMS-FGA
pip install -e ".[dev]"
python -m src
```

## 2. Подготовка данных

### Формат CSV

Программа принимает три CSV-файла, полученные методом HPLC-HRMS:

| Файл | Описание |
|------|----------|
| **Исходный спектр** | Недериватизированный образец |
| **Дейтерометилирование** | Образец после CD₃-метилирования (–COOH → –COOCD₃) |
| **Дейтероацилирование** | Образец после CD₃CO-ацилирования (–OH → –OCOCD₃) |

### Требования к колонкам

```csv
mass,intensity
100.0518,245030.0
101.0597,123410.5
...
```

- Разделитель: запятая или табуляция
- Колонки: `mass` (или `m/z`) и `intensity`
- Массы в Dalton, интенсивности в условных единицах

### ThermoRAW (Windows, опционально)

При наличии `.raw`-файлов программа автоматически усреднит спектры
по заданному RT-диапазону. Требуется установка Thermo RawFileReader DLL
(см. [инструкцию](https://github.com/thermofisherlsms/RawFileReader)).

## 3. Запуск анализа

### Загрузка спектров

1. Откройте вкладку **Параметры**
2. Для каждого из трёх спектров нажмите **Обзор** и выберите CSV-файл
3. При необходимости укажите RT-диапазон для `.raw`-файлов

### Настройка параметров

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| Пресет | — | Набор параметров для типа образца (см. [Пресеты](#5-пресеты)) |
| Относительная ошибка, ppm | 1.0 | Допустимое отклонение массы |
| Денойз | auto (GMM) | Метод шумоподавления: auto, quantile или порог |
| Сила денойза | 1.0 | Множитель порога (1.0–3.0) |

### Запуск

Нажмите **▶ Запустить анализ**. Ход выполнения отображается в строке статуса.
Результаты появятся на соответствующих вкладках.

## 4. Интерпретация результатов

### Вкладка «Спектры»

Отображает три спектра (исходный, дейтерометилированный, дейтероацилированный)
с разметкой пиков. Для каждого пика показана назначенная брутто-формула.

### Вкладка «Результаты»

Таблица со столбцами:

| Колонка | Описание |
|---------|----------|
| `mass` | Наблюдаемая m/z |
| `intensity` | Интенсивность пика |
| `brutto` | Назначенная брутто-формула |
| `N_COOH` | Число карбоксильных групп |
| `N_OH` | Число гидроксильных групп |
| `missing_dmet` | Отсутствует в дейтерометилированном спектре |
| `missing_dacet` | Отсутствует в дейтероацилированном спектре |

### Диаграмма Ван-Кревелена

Вкладка **Van Krevelen** — график H/C vs O/C для всех идентифицированных
соединений. Области графика соответствуют классам NOM:

- Липиды (H/C 1.5–2.0, O/C 0–0.3)
- Белки/пептиды (H/C 1.5–2.0, O/C 0.3–0.6)
- Лигнины (H/C 0.7–1.5, O/C 0.1–0.7)
- Танины (H/C 0.5–1.5, O/C 0.6–1.0)
- Конденсированные ароматические соединения (H/C 0.3–0.7, O/C 0–0.7)

### Гомологические серии

Вкладка **Серии** показывает цепочки соединений, отличающихся на CH₂-группу.

## 5. Пресеты

Пресет — набор параметров, оптимизированный под тип образца.

| Пресет | Рекомендуется для | Особенности |
|--------|-------------------|-------------|
| `soil` | Почвенные образцы | Широкий диапазон масс, высокое разнообразие |
| `peat` | Торф | Низкая степень ароматизации |
| `coal` | Уголь | Высокая ароматичность, низкий H/C |
| `water` | Водные образцы | Низкая концентрация, узкий диапазон масс |

Выберите пресет на вкладке **Параметры** — все настройки заполнятся автоматически.

## 6. Частые ошибки и их решение

### «Python не найден» при установке через pip

Переустановите Python с официального сайта [python.org](https://python.org),
отметив галочку **«Add Python to PATH»**.

### «Неверный формат файла»

Убедитесь, что CSV содержит колонки `mass` (или `m/z`) и `intensity`.
Разделитель — запятая или табуляция.

### «Нет результатов» после анализа

Возможные причины:

- Неправильно выбран пресет — попробуйте другой
- Слишком узкий диапазон масс — проверьте параметры `min_mass` / `max_mass`
- Низкое качество данных — увеличьте `rel_error_ppm` до 2.0–3.0

### «RawFileReader not available»

Ошибка возникает при попытке загрузить `.raw`-файл без установленных DLL.

- Убедитесь, что 4 файла RawFileReader DLL находятся в папке `thermo/`
- Проверьте, что установлен `pythonnet`: `pip install pythonnet>=3.0`

### Приложение не запускается на Linux

Установите tkinter: `sudo apt install python3-tk`.
