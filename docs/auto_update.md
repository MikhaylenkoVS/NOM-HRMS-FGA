# Автообновление по GitHub Releases

Утилита: `tools/auto_updater.py`.
Проверка встроена в `tools/launcher.py` для собранного `NOM_HRMS_FGA.exe`.

## Как работает

1. При запуске exe в фоне запрашивается
   `https://api.github.com/repos/MikhaylenkoVS/NOM-HRMS-FGA/releases/latest`.
2. Версия из `tag_name` сравнивается с `src.__version__`.
3. Если тег новее, показывается вопрос «Скачать и установить?».
4. Exe скачивается во временную папку, затем создаётся `.bat`, который
   после выхода процесса заменяет текущий exe и перезапускает его.

Обновление **не** выполняется:
- в dev-режиме (`python tools/launcher.py`), только для frozen exe;
- при `NOM_HRMS_DISABLE_UPDATE=1`;
- если в релизе нет `.exe`-ассета.

## Требования к релизу

- Тег вида `v0.10.0` (сравнение по числам).
- Ассет `NOM_HRMS_FGA.exe` (или имя, содержащее `NOM` и `.exe`).
- Желательно приложить `.sha256` и проверять его вручную/CI.

## CLI

```bash
python tools/auto_updater.py --check
python tools/auto_updater.py --update
```

`--check` только печатает текущую/последнюю версию и ассет.
`--update` скачивает и планирует замену.

## Ограничения

- Нет подписи кода; для коммерческого распространения нужен
  Authenticode-сертификат.
- GitHub API имеет лимит 60 запросов/час без токена; одного запроса на
  запуск достаточно.
- При отсутствии UPX exe занимает ~675 МБ; для уменьшения размера
  установите UPX или используйте onedir-сборку.
