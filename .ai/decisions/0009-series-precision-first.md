# ADR 0009: точность прежде полноты в поиске серий дериватизации

* Статус: принято
* Дата: 2026-10-17
* Затрагивает: `src/core/spectrum/_series.py`, `src/core/pipeline/`,
  `src/configs/pipeline.json`

## Контекст

Проверка на Fulvagra F16 показала, что прежние оценки (среднее N_COOH 14,
у 37 % соединений ровно 20) не соответствуют литературе по гуминовым веществам
(для фульвокислот ≈ 5–6 мэкв/г COOH, что при 400–500 Да даёт 2–3 группы на
молекулу). Причина — ложные срабатывания поиска серий: при 5 ppm и плотности
спектра дериватизата 3.1 мДа между пиками вероятность случайного попадания в
окно ≈ 97 % на шаг, то есть 20-шаговый зонд «находит» серию почти без
дериватизации. Старые числа измеряли плотность пиков, а не химию.

## Решение (приоритет — точность)

1. **Обязательная первая ступень.** Серия считается только при подтверждённой
   ступени n = 1 (монодериватизированный продукт). Без неё нет доказательства
   дериватизации вообще, а «ступени» 2..n — вероятные совпадения.
   Параметр `require_first_step` (по умолчанию `True`).
2. **Ужесточены умолчания:**
   * `denoise_derivatives = true` — шумоподавление дериватизатов;
   * `subtract_source = true`, `subtract_ppm = 2.0` — вычитание исходника
     (модель «один к одному»);
   * `ppm_tol = 2.0` — окно поиска серий вместо 5 ppm.
3. Бюджет пропусков остаётся 1 (ADR-0007): правило не отменяется, но при
   отсутствии первой ступени оно уже не спасает серию.

## Принцип

Честный результат «COOH ≥ 1» предпочтительнее «COOH ≥ 4», полученного за счёт
попадания в ложный пик. Пропуск настоящей группы (ложноотрицательный результат)
допустим; ложное подтверждение — нет.

## Последствия

* Средние N_COOH/N_OH снижаются до физиологичного диапазона (2–4).
* Часть соединений теряет серии (нет подтверждения первой ступени) — это
  ожидаемо и трактуется как «нет данных», а не как ноль.
* Для чувствительных образцов окно можно ослабить вручную
  (`--ppm-tol`, `--subtract-ppm`), но это уже сознательный выбор пользователя.
