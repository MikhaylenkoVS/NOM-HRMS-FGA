# Rollback Plan — PACKAGING-01

## Тип изменения

Только упаковочная конфигурация и тексты документации. Код `src/`, `tests/`,
`data/` не изменяется. Научные результаты не затрагиваются — подтверждается
побайтовым сравнением вывода на `set_01` (A10, A11).

## Откат

### Полный откат ветки

Работа ведётся в `dev`, обновлённом fast-forward до `main`
(`30194d66eb259902bab3a36860068223dabace4c`). Полный откат:

```bash
git checkout dev
git reset --hard 30194d66eb259902bab3a36860068223dabace4c   # ТОЛЬКО по явной команде человека
```

> `git reset --hard` на общей ветке — операция из списка запрещённых
> (`AGENTS.md`, правило 5; `code-change-protocol`, раздел 4). Выполняется
> исключительно по письменному указанию владельца репозитория.

### Точечный откат (предпочтительно)

Работа разбита на отдельные коммиты; откат — обратными коммитами:

```bash
git revert SHA             # для каждого коммита задачи, в обратном порядке
```
