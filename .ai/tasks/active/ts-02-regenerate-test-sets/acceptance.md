# TS-02 — критерии приёмки

- [ ] Для каждого набора создан `capabilities.json` с фактическим составом.
- [ ] Наборы содержат изотопные сателлиты (проверяется программно: для каждого
      сигнала с C >= 5 в спектре есть пик на M+1 в пределах 5 ppm).
- [ ] Наборы содержат галогенсодержащие соединения (F, Cl, Br, I).
- [ ] Есть поднаборы разной плотности (500 / 2000 / 8000 пиков).
- [ ] Есть отрицательные контроли, по которым считается `wrong_ratio`.
- [ ] Интеграционные тесты используют флаги, соответствующие возможностям
      набора (изотопные проверки включаются только там, где есть сателлиты).
- [ ] Зафиксированы baseline-метрики по каждому набору.
