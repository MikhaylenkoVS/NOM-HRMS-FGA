# TS-02 — дизайн генератора тест-сетов

## Зачем

Текущие наборы (`set_01`–`set_05`, версия v0.4) содержат только CHNO-формулы
без изотопных сателлитов. Поэтому на них нельзя проверить:

* изотопные правила (M+1/M+2, поиск вариантов, атрибуцию сателлитов);
* работу с галогенами, серой и фосфором;
* устойчивость поиска серий на плотных спектрах (ложные совпадения).

## Что должно быть в наборе

| Блок | Требование |
|---|---|
| Изотопы | M+1/M+2 с отношениями из таблицы изотопов; часть соединений — с S/Cl/Br, часть — только 13C |
| Элементы | CHNO + S, P + F, Cl, Br, I (по отдельности и в комбинациях до 5 атомов) |
| Дериватизация | CD3 и CD3CO-серии, включая полную дериватизацию (>= 4 групп) и частичную |
| Плотность | поднаборы 500 / 2000 / 8000 пиков, включая изобары и шумовые пики |
| Контроли | negative-control: пики без формулы, соседи на ±1 и ±2 Да (проверка, что изотопные проверки не путают соседей с сателлитами) |
| Дескриптор | `capabilities.json`: что реально есть в наборе (сателлиты, элементы, состояния) |

## Требования к эталону

* Для каждого сигнального пика — точная нейтральная масса, брутто-формула,
  число групп COOH/OH, интенсивность.
* Массовая точность не хуже 1 ppm для всех сигналов.
* Явно перечислены шумовые пики (is_signal=false) — по ним считается точность
  (доля ложных назначений).

## Метрики на наборе

1. `denoise_recall` — доля сохранённых сигнальных пиков.
2. `assign_recall` — доля сигналов с верной формулой.
3. `wrong_ratio` — доля назначений на шумовых пиках.
4. `isotope_variant_accuracy` — доля верно подтверждённых изотопных вариантов.
5. `group_accuracy` — точность N_COOH/N_OH (в том числе на плотных поднаборах).
