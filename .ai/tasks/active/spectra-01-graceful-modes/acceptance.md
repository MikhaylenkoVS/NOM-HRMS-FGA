# Приёмочные критерии

## R2 (мягкая деградация)

- [ ] Пайплайн с одним исходным спектром завершается успешно, таблица не пустая,
      `assigned_count > 0` на тест-сете set_01.
- [ ] Пайплайн с исходником и `dmet` считает `N_COOH`, не считает `N_OH`,
      результат помечен как сокращённый.
- [ ] Отсутствие всех трёх файлов по-прежнему даёт понятную ошибку.
- [ ] `PipelineStats.degraded_modes` содержит список пропущенных стадий с причиной.
- [ ] CLI без `--dmet/--dacet` работает; в GUI результат помечен как сокращённый.
- [ ] Тест: результат в сокращённом режиме не выдаёт себя за полный
      (в таблице и в метаданных есть признак).

## R1 (наложения дериватизатов)

- [ ] На синтетическом спектре с искусственным наложением соединение помечается
      `derivatization_overlap`, в диагностике есть пара масс и ppm.
- [ ] На реальном set_01 число помеченных наложений < 5 % соединений (иначе
      пороги подобрать заново).
- [ ] Подсчёт групп N_COOH/N_OH согласован с решением заказчика по открытому
      вопросу 1.
- [ ] Диагностический рисунок сохраняется в материалах для статьи.
