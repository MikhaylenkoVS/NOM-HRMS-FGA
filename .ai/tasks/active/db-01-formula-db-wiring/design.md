# DB-01 — дизайн

## Цель

1. Убрать главного «тормоза» назначения — перебор формул (50–450 мс на пик).
2. Сделать сжатую базу формул рабочим источником кандидатов.
3. Добавить галогены без пересборки базы (формат uint32 занят целиком).
4. Пробросить изотопные проверки (M+1/M+2, варианты, сателлиты) в обычный
   прогон GUI/CLI и дать пользователю отдельное окно со списком изотопов.

## Архитектура

| Слой | Модуль | Роль |
|---|---|---|
| Источник формул | `core/spectrum/_formula_source.py` (новый) | `open_formula_db`, `db_candidates`, `halogen_combos`, фильтры плаузибельности |
| База | `core/formula_db/_reader.py`, `_packed.py` | чтение блоков, поиск по массе; исправлены баги |
| Назначение | `core/spectrum/_assign.py` | выбор источника, кэш окон, изотопные штрафы/бонусы, атрибуция сателлитов |
| Отчёт | `core/spectrum/_build.py` | колонки `iso_variants`, `iso_satellite_of`, `iso_satellite_label`, исключение сателлитов |
| Пайплайн | `core/pipeline/_run.py`, `_segments.py` | открытие/закрытие базы, проброс `isotope_variants`, дефолты |
| GUI/CLI | `ui/_params.py`, `app.py`, `cli.py` | галочки, флаг `--isotope-variants`, окно «Список изотопов» |

## Алгоритм

1. Пайплайн открывает базу один раз (`open_formula_db()`); при отсутствии файла
   `formula_db=None` → назначение работает перебором.
2. Для каждого пика строится нейтральное окно ±ppm (сетка 0.001 Да, кэш).
3. `db_candidates(reader, cfg, center, half, include_halogens)`:
   * запрос `reader.search(center, ppm, element_filter)` → формулы CHNOSP;
   * при `include_halogens` — дополнительные запросы по `center − Δ` для
     комбинаций галогенов (по умолчанию до 1 атома), с добавлением комбинации
     к найденной формуле;
   * все кандидаты проходят те же жёсткие фильтры, что и перебор.
4. Гейт галогенов: `M+2/M ≥ 5 %` (Cl ≈ 32 %, Br ≈ 97 %) или пустой CHNOSP-набор.
5. Скоринг/изотопные проверки — как в ADR-0004 (поатомные штрафы, бонус за M+2).
6. После выбора формул: поиск изотопных вариантов (колонка `iso_variants`) и
   атрибуция сателлитов (поиск пика на `m + Δ` с совпадением отношения
   интенсивностей); сателлиты исключаются из отчёта.

## Ключевые решения

* Галогены — слоем подстановок, а не новой базой (см. ADR-0005).
* Гейт по M+2: бесплатный и надёжный для Cl/Br; ценой того, что чистый фтор
  находится только когда CHNOSP-вариантов нет.
* Сателлиты помечаются по отношению интенсивностей (допуск `satellite_tolerance`
  = 0.35) и по m/z в окне `variant_ppm_tol` = 5 ppm.
