## Сопоставление источников формул

Для 204 назначенных пиков сравнение «перебор против базы» дало: 146 формул
совпали, 22 пика назначены только перебором, 0 — только базой, 58 — с другой
формулой той же массы. Различия объясняются тем, что перебор применяет лимиты
отношений **во время** генерации, а база отдаёт CHNOSP-кандидатов, которые затем
фильтруются; порядок отсечения влияет на состав окна. Точность на эталонных
тест-сетах (главный критерий) сохранена: интеграционные тесты проходят.

## Изотопные проверки на эталоне

Синтетические тест-сеты не содержат изотопных сателлитов (ближайший пик к
M+1 находится на 50–1000 мДа, отношение интенсивностей ≤ 1 %), поэтому в отчёте
по тест-сетам колонки `iso_variants` пусты, а `iso_satellite_of` не заполняется.
Это ожидаемое поведение: изотопные проверки активируются на реальных спектрах,
где паттерн присутствует.

Корректность изотопной логики подтверждена отдельными проверками:

* C7H6O2: M+1 теор. 0.0757, измер. 0.0772 → `ok`, сателлит помечен `13C`;
* C6H5Cl2O: M+2 теор. 0.6399, измер. 0.6438 → `ok` (37Cl);
* CHCl3 M+2 = 96 %, CHBr M+2 = 97 %, C6H12O6 M+1 = 6.86 % (теоретический паттерн).
