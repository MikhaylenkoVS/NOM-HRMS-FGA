# Acceptance — GUI-01

## Критерии приёмки

| # | Критерий | Метод проверки | Ожидаемый результат |
|---|---|---|---|
| G1 | `sign="+"` меняет режим ионизации | юнит-тест `_ion_mode_from_sign` + тест назначения | `"+"` → `[M+H]+`, `"-"` → `[M-H]-` |
| G2 | `sign` влияет на назначение формул | регрессионный тест на синтетических m/z, где [M-H]- и [M+H]+ дают разных кандидатов | разные `brutto` |
| G3 | `brutto_dict` ограничивает генерацию | тест: узкий диапазон C:1-3 не даёт формул с C>3 | все формулы в диапазоне |
| G4 | Пресет шумоподавления маппится в метод+значение | юнит-тест чистой функции маппинга | `noise_intensity=300` → метод `intensity`, значение `300` |
| G5 | Мёртвые переменные удалены | grep `noise_force_var\|noise_int_var` | только в тестах/истории, не в src/ |
| G6 | Дефолтный результат не изменился | CLI на set_01 + md5 | `33cde0049db29f91dfeab2c71d13b77e` |
| G7 | Все тесты зелёные | `pytest tests/ -q` | 0 failures |
| G8 | Task packet валиден | `python tools/ai_workflow.py validate-task gui-01-settings-wiring` | 0 errors |
| G9 | ADR создан и в индексе | `.ai/decisions/0002-*.md`, `index.md` | ссылка в `task.json → links.adr` |
