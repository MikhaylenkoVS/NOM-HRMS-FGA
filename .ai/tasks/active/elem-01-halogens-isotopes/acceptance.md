# ELEM-01 — критерии приёмки

## Функциональные

- [x] Элементы в назначении: C, H, O, N, S, P, F, Cl, Br, I.
- [x] Список элементов и диапазоны задаются только конфигом
      (`configs/constants/formula_search.json`); код не дублирует перечень.
- [x] Изотопная таблица содержит массу и природную распространённость для всех
      элементов назначения.
- [x] `pattern(counts)` возвращает `[1, M+1/M, M+2/M, …]`; проверено на
      C7H6O2 (M+1 ≈ 7.7 %), CHCl3 (M+2 ≈ 96 %), CHBr (M+2 ≈ 97 %),
      C6H12O6 (M+1 ≈ 6.9 %).
- [x] `variants(counts)` даёт изотопные варианты с метками (`13C`, `37Cl`, `34S`),
      точным сдвигом массы и вероятностью.
- [x] `find_isotope_variants(...)` находит вариант в наблюдаемом спектре и
      сравнивает измеренное отношение с теоретическим.
- [x] Штрафы S/P/галогенов по атомам; бонус при совпадении M+2.
- [x] DBE считается с N и P, галогены учитываются как X.
- [x] GUI: поля диапазонов строятся из `self.el_vars` (10 элементов),
      валидация ловит нечисловые значения и max < min.
- [x] CLI: элементы берутся из конфига; `--element-ranges` принимает новые
      символы (`C:5-60,H:4-120,O:1-30,N:0-3,S:0-2,Cl:0-1`).

## Нефункциональные

- [x] Назначение на set_01 (316 пиков) завершается за приемлемое время
      (замер: ~66 с).
- [x] Точность назначения на эталонных формулах set_01 не ухудшена:
      интеграционный тест `test_pipeline_denoise_assign_find_series_on_existing_sets[set_01]`
      проходит.
- [x] Никаких новых runtime-зависимостей.

## Проверочные команды

```bash
  --input data/test_sets/set_01/original.csv \

  --sep , -o result_set01.xlsx
```

## Открытый вопрос (не блокирует приёмку)

Широкие пределы галогенов (X/C ≈ 0.5) в текущем переборе дают часы на спектр —
нужен этап 4 (поиск по сжатой базе формул). Зафиксировано в ADR-0004.
