# ELEM-01 — дизайн

## Цель

Назначение брутто-формул должно учитывать не только CHNO, но и S, P и галогены
(F, Cl, Br, I), а изотопный контроль — работать по таблице изотопов
(M/M+1/M+2) и уметь находить изотопные варианты найденной формулы.

## Архитектура

| Слой | Модуль | Роль |
|---|---|---|
| Данные | `configs/chemistry.json` | моноизотопные массы элементов |
| Данные | `configs/constants/formula_search.json` | элементы, диапазоны, лимиты отношений, штрафы |
| Данные | `configs/constants/isotope.json` | таблица изотопов (масса + распространённость), параметры паттерна |
| Логика | `core/spectrum/_constants.py` | `FormulaSearchConfig`, `HALOGENS`, валентности |
| Логика | `core/spectrum/_generate.py` | перебор формул под массовое окно (DFS + отсечения) |
| Логика | `core/spectrum/_isotopes.py` | паттерн, изотопные варианты, сопоставление с пиками |
| Логика | `core/spectrum/_assign.py` | поиск под каждый пик, скоринг, изотопные штрафы/бонусы |
| Логика | `core/spectrum/_chem.py` | строки формул из количеств (элемент-агностично) |
| GUI | `src/app.py`, `src/ui/_params.py` | поля диапазонов строятся из конфига |

## Алгоритм

1. Для каждого пика `m/z` строится нейтральное окно `±rel_error_ppm` (с поправкой
   на ионный режим).
2. `_generate_cached(...)` перебирает формулы в этом окне:
   * цикл по C, затем DFS по «тяжёлым» элементам (по убыванию массы) с
     отсечением по достижимой массе (`need`/`room`);
   * диапазон H вычисляется в конце из условий:
     `DBE = (2C + 2 + N + P − H − X)/2 ≥ 0`, `DBE ≤ max_dbe`,
     чётность числителя (правило Льюиса — сумма валентностей чётна);
   * жёсткие лимиты отношений: H/C, O/C, N/C, S/C, P/C, X/C.
3. Скоринг кандидатов: `nom_weight·NOM_distance(O/C, H/C)` + штрафы за высокий
   DBE, N-экзотику и **по атомам** за S/P/галогены.
4. Если включён `isotope_filter` и есть исходный (до шумоподавления) спектр:
   * M+1: измеренное отношение против теоретического (по таблице) — штраф при
     расхождении > `tolerance`;
   * M+2: для кандидатов с S/Cl/Br — штраф при расхождении и **бонус** при
     совпадении (изотопное подтверждение «нестандартного» состава).
5. При `isotope_variants=True` для выбранной формулы в колонку `iso_variants`
   пишутся изотопные варианты (`13C`, `37Cl`, `34S`, …) с ожидаемой m/z,
   теоретическим и измеренным отношением.

## Ключевые решения

* **Кэш генератора** — по окну, округлённому к сетке 0.001 Да, чтобы одинаковые
  окна не пересчитывались.
* **Умеренные лимиты отношений** (S/C 0.2, P/C 0.1, X/C 0.1) — результат замеров
  времени (см. implementation_report). Широкие лимиты требуют поиска по сжатой
  базе формул (follow-up).
* **Консервативный скоринг**: без изотопного подтверждения S/P/галоген-формула
  не должна перебивать CHNO-вариант в том же ppm-окне.
