# ELEM-01 — сверка с эталоном (reference validation)

## Что считается эталоном

* Тест-сет `data/test_sets/set_01` с аннотированными брутто-формулами
  (31 соединение).
* Пороги из `src/configs/pipeline.json -> thresholds`:
  `min_denoise_recall = 0.90`, `min_assign_recall = 0.90`,
  `max_wrong_ratio = 0.15`.

## Проверка

Команда:

```bash
python -m pytest -q \
  "tests/integration/test_pipeline_integration.py::test_pipeline_denoise_assign_find_series_on_existing_sets[set_01]"
```

Результат после доработки скоринга: **PASSED** (≈3 мин).
Это означает, что доля пиков, для которых назначена ожидаемая эталонная формула,
не ниже `min_assign_recall = 0.90`, а доля ошибок не выше `max_wrong_ratio`.

## Ход работы (что показала сверка)

| Вариант скоринга | Результат |
|---|---|
| Базовая версия (только CHNO, штрафы за S/P/галогены отсутствуют) | PASSED (эталон — 119 строк результата) |
| Расширенные элементы, штрафы «мягкие» (0.30 × отношение S/C+P/C+X/C) | **FAILED**: `assigned_ok = 24/31 (77.4 %)` — галогенные формулы (`C25F2H48OS`, `C26ClH47NO5PS2`) перебивали верные CHNO-формулы |
| Расширенные элементы, штрафы по атомам (S 1.0, P 1.5, галоген 1.5) + бонус за M+2 | **PASSED** (принято) |

Промежуточный вариант отвергнут именно по результатам этой сверки — он и стал
причиной введения поатомных штрафов и «доказательного» бонуса по M+2.

## Числа полного прогона CLI (set_01)

```
Назначено формул: 226 из 316 пиков
Соединений с сериями CD3: 32
Соединений с сериями CD3CO: 11
Строк в таблице: 226
```

До изменения набор элементов был CHNO, и строк результата было 119. Рост числа
назначенных пиков ожидаем: расширен химический состав поиска (S, P, галогены) и
исправлен DBE в скоринге (использовался кислород вместо азота).

## Эквивалентность CHNO-поведения

* Генератор формул в режиме «только CHNO и без лимитов отношений» даёт ровно
  **198 240** кандидатов на окне 150–800 Да — совпадает с прежней реализацией
  (проверено вручную, см. `implementation_report.md`).
* Строки формул для CHNO не изменились: `_counts_to_str` сохраняет порядок
  C, H, O, N, S, P, F, Cl, Br, I.

## Известные отклонения

* Время назначения на set_01 ≈ 66 с (ранее ≈ 2 с). Причина — перебор формул под
  каждый пик с расширенным набором элементов. Для спектров с десятками тысяч
  пиков требуется поиск по сжатой базе формул (follow-up этап 4, ADR-0004).
